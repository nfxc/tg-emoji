# tg-emoji

Коллекция анимированных эмодзи из Telegram в формате GIF, разложенных по тематикам.

![format](https://img.shields.io/badge/format-GIF-ff69b4)
![source](https://img.shields.io/badge/source-Telegram-26A5E4?logo=telegram)
![license](https://img.shields.io/badge/license-MIT-green)

## 🗂 Структура

```text
tg-emoji/
├── crypto/     # Крипто-эмодзи
├── crypto2/    # Вторая подборка крипто-эмодзи
├── ios/        # Эмодзи в стиле iOS
├── ios2/       # Вторая подборка эмодзи в стиле iOS
└── service/    # Служебные эмодзи
```

## 🏷 Категории

| Папка | Описание |
|-------|----------|
| `crypto/` | Анимированные эмодзи на криптовалютную тематику |
| `crypto2/` | Дополнительная подборка крипто-эмодзи |
| `ios/` | Эмодзи, стилизованные под iOS |
| `ios2/` | Вторая подборка эмодзи в стиле iOS |
| `service/` | Служебные и сервисные эмодзи |

## ⚠️ Дисклеймер

**Мне ничего из этого не принадлежит.**

Все эмодзи взяты из Telegram и принадлежат их авторам. Я не являюсь автором, правообладателем или создателем этих GIF-файлов — я лишь собрал их в одном месте и разложил по тематикам для удобства.

Если вы автор какого-либо эмодзи и хотите, чтобы его убрали — напишите, и я удалю его.
